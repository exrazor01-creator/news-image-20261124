A pure-stdlib Python program that draws a one-page newspaper front page, "THE WORLD TODAY", summing up Tuesday 24 November 2026 in a single 1024x1024 image: six stories from the Strait of Hormuz to the Las Vegas Grand Prix, each with a hand-drawn pictogram, headline, and short summary. It writes the PNG byte-for-byte deterministically, with no network and no third-party libraries.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (to `/output/entry.png` when `/output` exists, otherwise `./entry.png`).
